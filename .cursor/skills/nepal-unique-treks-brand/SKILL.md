# Nepal Unique Treks Brand

## 3. Recommended website color system
For the Nepal Unique Treks website, I recommend using this hierarchy:

Website element

Color

Primary buttons

`#22845F`

Button hover

`#176B4B`

Headings

`#1F6B93`

Links

`#22845F`

Secondary buttons

`#1F6B93`

Highlights / badges

`#E9A544`

Background

`#FFFFFF`

Section background

`#F3F8F5`

Body text

`#444746`

## Applying the palette

- Treat this palette as the source of truth for future theme changes.
- Use the shared `index.css` design tokens and shared component styles rather than adding duplicate page-specific colors.
- Keep primary actions green, secondary actions and headings blue, and amber for small highlights or badges.
- Preserve readable contrast for text placed on colored backgrounds.
- When changing shared CSS, update the `index.css` cache version on all HTML pages that reference it.
